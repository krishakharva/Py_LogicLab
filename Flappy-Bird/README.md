# 🐦 Flappy Bird Game using Python

A modern recreation of the classic **Flappy Bird** built entirely with **Python** and **Pygame**. The game features dynamic difficulty scaling, smooth gameplay, a scoring system, and a polished user interface.

---

## 🎮 Features

- 🐤 Smooth bird movement with gravity and jumping mechanics.
- 🌳 Randomly generated pipe obstacles.
- 📈 Dynamic difficulty that increases as your score grows.
- 🏆 High score tracking during the session.
- 🎨 Clean and colorful UI with animated clouds.
- ▶️ Start menu and Game Over screen.
- ⚡ Optimized for smooth 60 FPS gameplay.

---

## 🚀 Dynamic Difficulty

The game starts easy and gradually becomes more challenging.

| Score | Pipe Gap | Pipe Speed | Gravity | Spawn Rate |
|------:|----------|-----------:|---------:|-----------:|
| 0–2 | Very Wide | Slow | Low | Slow |
| 3–6 | Wide | Slightly Faster | Increased | Faster |
| 7–11 | Medium | Moderate | Medium | Moderate |
| 12–17 | Smaller | Fast | Higher | Faster |
| 18–24 | Challenging | Faster | Higher | More Frequent |
| 25–34 | Hard | Very Fast | High | Fast |
| 35–49 | Expert | Extremely Fast | Very High | Very Fast |
| 50+ | Insane Mode 🔥 | Maximum Speed | Maximum Gravity | Maximum Spawn Rate |

---

## 🛠 Requirements

- Python 3.10 or later
- Pygame 2.6+

Install Pygame:

```bash
pip install pygame
```

---

## ▶️ Run the Game

```bash
python main.py
```

---

## 🎯 Controls

| Key | Action |
|------|--------|
| **SPACE** | Start Game / Make the Bird Fly |
| **ESC** | Exit Game |

---

## 🏆 Scoring

- Earn **1 point** for every pipe successfully crossed.
- The game speed automatically increases as your score rises.
- Try to beat your **High Score**!
