# Tic Tac Toe in Python

A Tic Tac Toe game built using Python and Pygame.

## Features

- 🎮 Player vs Player mode
- 🤖 Player vs AI mode
- ✨ Smooth animations
- 🎨 Modern UI

## Requirements

- Python 3.x
- Pygame

Install Pygame:

```bash
pip install pygame
```

Run the game:

```bash
python main.py
```
